# Task-scoped commit policy

- Scope: document the owner's requirement to separate commits by task and coordinate with existing work.
- Plan: align AGENTS.md, README.md and the development workflow; check consistency, links, whitespace and scoped diff; commit only this task.
- Acceptance: task separation, existing-change preservation, overlap coordination and multiple verified increments per task are explicit.
- Constraints: preserve unrelated SDK migration edits; documentation only, no build/deployment or feature attempts.
