# 03. UDP 仕様

## 要件

- BveEx から得た情報をそのまま配信する
- パケット内容は後日検討する（本版では固定しない）

## インターフェース方針

- 低遅延配信を重視
- fire-and-forget（到達保証なし）
- UDPペイロードは UDP 専用仕様として定義する（シリアルと共通化しない）

## 暫定実装（2026-04-03）

- Main スレッド（BveEx Tick）では UDP 送信を直接実行しない。
- `BlockingCollection` キューへ `UdpTelemetryPacket` を投入し、専用ワーカースレッドが dequeue して送信する。
- キュー上限は 256 件。満杯時は古い処理遅延を避けるため新規投入をドロップする。
- シャットダウン時は `CompleteAdding` と `Join` で安全停止を試行する。

### 暫定送信ペイロード

- UTF-8 の CSV 文字列。
- 形式: `現在位置,現在速度,ドア開閉状態,ハンドル位置`
- 例: `123.4,45.6,open,3`
