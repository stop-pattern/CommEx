# 07. 設定画面要件

## 共通

- UDP / API サーバー / COM ポートを個別に有効・無効切り替え可能
- 設定の保存・再読込が可能

## UDP 設定

必要項目:

- 自身の IP アドレス表示
- 宛先 IP アドレス設定

追加条件:

- NIC が複数ある場合、NIC ごとに設定可能
- ローカルエコー / ループバックは表示対象外

## API サーバー設定

必要項目:

- ポート番号設定

## COM ポート設定

必要項目:

- 使用プロトコル（ドロップダウン）
  - bids互換（EX/TR）
  - communication.dll互換
  - BveSerialOutput互換
  - バイナリ独自形式
- 使用 COM ポート（ポートごとに設定項目をまとめる）
- 任意数のポートを同時利用可能
- ボーレート
- データビット
- ストップビット
- パリティ
- DTR / RTS（チェックボックス）
- 自動起動設定（チェックボックス）
